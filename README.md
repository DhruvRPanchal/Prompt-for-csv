# Ask Your CSV 🤖📊

> Chat with your CSV files using natural language.

Ask Your CSV is an AI-powered data analysis tool that allows users to upload CSV files and interact with their data through simple conversational prompts. Instead of manually filtering rows or writing complex queries, users can ask questions in plain English and instantly receive meaningful insights.

## ✨ Features

* 📁 Upload and analyze CSV files
* 💬 Ask questions in natural language
* 📊 Generate summaries and insights
* 🔍 Search, filter, and explore datasets
* ⚡ Fast and interactive chat interface
* 🤖 AI-driven data analysis

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/DhruvRPanchal/Ask-Your-CSV.git
```

### Navigate to the Project Folder

```bash
cd Ask-Your-CSV
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Configure Environment Variables

Create a `.env` file and add your API key:

```env
OPENAI_API_KEY=your_api_key_here
```

## ▶️ Run the Application

```bash
streamlit run main.py
```

Open the local URL generated by Streamlit in your browser.

## 📖 How to Use

1. Launch the application.
2. Upload your CSV file.
3. Enter questions or commands in the chat interface.
4. Receive AI-generated responses and insights based on your data.
